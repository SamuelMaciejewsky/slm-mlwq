# paper-mlwq-samuel

Research workspace for the MLWQ paper (Multi-Level Weight Quantization for SLM deployment).

## Layout

- `PDFs/papers/core/` — core papers the work builds on
- `PDFs/papers/related/` — secondary / related reading
- `PDFs/books/` — reference books (parallel computing, GPU architecture)
- `docs/` — notes and write-ups
- `mlwq/` — submodule with the paper code (https://github.com/SamuelMaciejewsky/mlwq)

## Submodule

```sh
git clone --recurse-submodules <this-repo>
# or, after a normal clone:
git submodule update --init --recursive
```
